## ⚠️ Demo Notice (Please Read Before Testing)

🔗 Live Demo: https://diya-fullsystem.vercel.app/

This project is hosted using **free-tier cloud services**.
Because of that, the backend server goes into sleep mode when inactive.

### What to expect during testing

1. When you click **“Send OTP” for the first time**, the backend server may be asleep.
2. Please wait **3–4 minutes** — the cloud provider needs time to wake up the server.
3. Once the server starts, the OTP will be **auto-filled on the screen**.
4. If the OTP does not appear after ~3 minutes, please restart the flow from **“Get Started”** and try again.

*(After the first wake-up, the app works normally for some time.)*
